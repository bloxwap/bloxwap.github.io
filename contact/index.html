Email

For account questions, the Bloxwap app, Bloxwap Pro, partnerships, or anything else, email support@bloxwap.com. Include as much detail as you can, such as the product you are using and what you expected to happen, so we can help on the first reply.

Chart SDK questions and bugs

For the open-source Bloxwap Chart SDK (@bloxwap/chart), open an issue on GitHub. Public issues let other developers find the answer later. A minimal example, your browser, and the library version make bugs much faster to fix. The documentation and the interactive playground answer many common questions.

Security

Please report security vulnerabilities privately by email to support@bloxwap.com rather than in a public issue.

Community

Follow product news on X and talk with the team and other traders on Discord. You can also browse all of our public projects in the Bloxwap GitHub organization.
