Hyperliquid SDK

@bloxwap/hyperliquid is a fast, fully typed TypeScript client for the Hyperliquid exchange API. Install it with npm i @bloxwap/hyperliquid.

Quickstart

Install the package and read your first market data.

Documentation

Installation, clients, transports, signing, error handling, and utilities.

API reference

SFX

@bloxwap/sfx is an interface sound-effects library for the web: 19 sounds for hovers, presses, toggles, confirmations, and money moments, synthesized with Web Audio — no audio files, zero dependencies. Install it with npm i @bloxwap/sfx.

Quickstart

Install the package and wire your first sounds with bind() and play().

Play all 19 sounds live and copy the call for each one.

Documentation

Declarative binding, React and other frameworks, sound design, and accessibility.

API reference

play, configure, renderTo, renderBuffer, encodeWav, and every other export.

Haptic

@bloxwap/haptic adds haptic feedback to React: physical-tap ticks on iOS and vibration patterns on capable browsers, while the target keeps its handlers, ref, focus, and accessibility. Install it with npm i @bloxwap/haptic.

Demo

Tap the board to feel each preset on a supported device.

Documentation

Installation, the wrapper component, presets, and platform support.

API reference

The Haptic component, presets, custom patterns, and every export.

Examples

Refs and focus, forms and links, drawer targets, and custom components.

Font

@bloxwap/font provides Bloxwap Sans, Mono, and Pixel: rounded variable typefaces for interfaces, code, and screens, with multilingual companions, under the SIL Open Font License. Install it with npm i @bloxwap/font.

Access and API keys

All five projects are keyless: there are no API keys, accounts, rate limits, or usage fees to manage. The Chart SDK runs entirely in your application — build it from source and ship it with your app. The Hyperliquid SDK talks directly to Hyperliquid's public API from your own code, and trading signs with your own wallet, never a Bloxwap account. SFX synthesizes every sound locally in the browser with Web Audio, Haptic runs on the device, and Bloxwap Font is a set of static font files.
