Chart SDK

@bloxwap/chart is a zero-dependency TypeScript library for interactive financial charts that runs in browsers, workers, server rendering, and tests.

Quickstart

Build the package and render your first candlestick chart in a few minutes.

Documentation

Guides for data, series, indicators, drawings, the toolbar, React, and performance.

API reference

The Chart API, configuration object, scale and coordinates, and package exports.

Sandbox

An interactive playground with every drawing tool and a simulated live feed.

Hyperliquid SDK

@bloxwap/hyperliquid is a fast, fully typed TypeScript client for the Hyperliquid exchange API. Install it with npm i @bloxwap/hyperliquid.

Quickstart

Install the package and read your first market data.

Documentation

Installation, clients, transports, signing, error handling, and utilities.

API reference

Every client method, parameter, and response type.

Guides

Market orders, agent wallets and vaults, browser wallets, and smaller bundles.

SFX

@bloxwap/sfx is an interface sound-effects library for the web: 19 sounds for hovers, presses, toggles, confirmations, and money moments, synthesized with Web Audio — no audio files, zero dependencies. Install it with npm i @bloxwap/sfx.

Quickstart

Install the package and wire your first sounds with bind() and play().

Sound board

Play all 19 sounds live and copy the call for each one.

Documentation

Declarative binding, React and other frameworks, sound design, and accessibility.

API reference

play, configure, renderTo, renderBuffer, encodeWav, and every other export.

Access and API keys

All three projects are keyless: there are no API keys, accounts, rate limits, or usage fees to manage. The Chart SDK runs entirely in your application — build it from source and ship it with your app. The Hyperliquid SDK talks directly to Hyperliquid's public API from your own code, and trading signs with your own wallet, never a Bloxwap account. SFX synthesizes every sound locally in the browser with Web Audio.
