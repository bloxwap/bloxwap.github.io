Agent CLI

@bloxwap/agent-cli is an agent-native Hyperliquid trading CLI with JSON input and output, a persistent signing runner, Relay funding, and paper trading against live mainnet market data. Master custody stays in your own wallet. Install it with npm i -g @bloxwap/agent-cli.

Smart Solana

@bloxwap/smart-solana is an adaptive Solana JSON-RPC transport for Solana Kit and web3.js. It routes by measured provider latency and errors, fails over when providers throttle or time out, and answers repeated reads from a local cache. Install it with npm i @bloxwap/smart-solana @solana/kit.

Smart HyperEVM

@bloxwap/smart-hyperevm is a drop-in viem transport for HyperEVM. It ranks RPC endpoints by live latency, errors, congestion, and block-head lag, races the best candidates, and answers recent reads from a local cache. Install it with npm i @bloxwap/smart-hyperevm.

Access and API keys

None of these projects needs a Bloxwap account, API key, or usage fee. The Chart SDK runs entirely in your application — install it from npm and ship it with your app. The Hyperliquid SDK talks directly to Hyperliquid's public API from your own code, and trading signs with your own wallet, never a Bloxwap account. Agent CLI signs with your own Privy app or a dedicated EOA agent key that you keep outside the CLI; it ships no shared credentials or hosted signer, and paper trading needs no credentials at all. Smart Solana and Smart HyperEVM default to keyless public RPC providers, and you can add your own provider URLs. SFX synthesizes every sound locally in the browser with Web Audio, Haptic runs on the device, and HIG and Bloxwap Font are packages and files you ship yourself.
