Access and keys

The Chart SDK is an open-source library that runs entirely in your application. There is no hosted service behind it, so there are no API keys, accounts, rate limits, or usage fees: build it from source under the MIT license and ship it with your app. The package is not yet published on npm; the quick start shows how to build and install it locally. The Hyperliquid SDK is published on npm; it talks directly to Hyperliquid's public API, and trading uses your own wallet, never a Bloxwap account.
