# bloxwap.github.io

The root GitHub Pages site for the Bloxwap organization: a static homepage, About/Contact/Privacy pages, `robots.txt`, `sitemap.xml`, and `llms.txt` for AI agents.

Project docs live in their own repositories and publish under this domain, e.g. the Chart SDK at https://bloxwap.github.io/chart/ from [bloxwap/chart](https://github.com/bloxwap/chart).

Plain HTML and CSS with no build step: edit the files and push to `main`. Keep `sitemap.xml` in step with the pages here and with the Chart SDK sitemap.
