Trading SDKs

Chart SDK

@bloxwap/chart — a zero-dependency TypeScript library for interactive financial charts.

Hyperliquid SDK

@bloxwap/hyperliquid — a fast, fully typed TypeScript client for the Hyperliquid exchange API.

Agent CLI

@bloxwap/agent-cli — Hyperliquid trading tools for agents, with JSON commands, Privy-managed signing, and Relay funding.

Smart Solana

@bloxwap/smart-solana — an adaptive, latency-aware Solana JSON-RPC transport for Solana Kit and web3.js, with retries, hedging, and failover across providers.

Smart HyperEVM

@bloxwap/smart-hyperevm — a latency-aware viem transport for HyperEVM that ranks endpoints from live calls and serves warm reads from cache.

Design

HIG

@bloxwap/hig — Bloxwap's Human Interface Guidelines: design tokens and React and React Native components for every Bloxwap surface.

Font

@bloxwap/font — rounded Sans, Mono, and Pixel typefaces for interfaces, code, and screens, with variable weights and multilingual support.

SFX

@bloxwap/sfx — interface sound effects for the web: 19 sounds synthesized with Web Audio, no audio files.

Haptic

@bloxwap/haptic — haptic feedback for React: physical-tap ticks on iOS and vibration patterns on capable browsers, with the target's handlers, ref, and accessibility intact.
