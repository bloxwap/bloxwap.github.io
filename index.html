Bloxwap on GitHub

This is the home of Bloxwap's open-source developer tools. The main project here is the Bloxwap Chart SDK, @bloxwap/chart: a TypeScript library for building interactive financial charts in your own product.

Bloxwap, Inc. builds trading products, including the Bloxwap app for trading crypto, stocks, gold, and indices, and the Bloxwap Pro terminal. The charting technology behind those experiences is published here under the MIT license, with documentation, runnable examples, and an interactive playground.

Bloxwap Chart SDK

The Chart SDK draws candlestick, OHLC bar, line, area, and histogram series onto an HTML canvas you provide. It has no runtime dependencies, accelerates its hot math paths with WebAssembly (falling back to plain JavaScript), and never touches the global document or window, so it runs in browsers, workers, server rendering, and tests.

It ships built-in indicators (SMA, EMA, Bollinger Bands, MACD, RSI, KDJ, and volume) and 89 drawing tools grouped the way trading terminals present them: trend lines, channels, pitchforks, Fibonacci and Gann tools, harmonic patterns, Elliott waves, long and short positions, measurers, shapes, and annotations. An optional UI layer adds a drawing toolbar, a settings card, and on-chart editing.
